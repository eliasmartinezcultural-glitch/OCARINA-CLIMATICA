# OCARINA CLIMÁTICA

## San Patricio del Chañar · V0.1.0

**El clima de nuestro lugar.**

Proyecto de Ocarina Producciones para construir un universo climático local: presente, pronóstico, series históricas, viento, lluvia, heladas, extremos, territorio, fotografías, testimonios y memoria.

### Reglas mundiales

1. **Profundidad oculta:** mucha estructura, sistema, datos y programación por detrás; experiencia fácil por delante.
2. **Curiosidad:** cada visita debe abrir una nueva pregunta o descubrimiento.
3. **Identidad territorial:** debe ser y parecer de San Patricio del Chañar, para Chañar.
4. **Rigor:** no inventar mediciones, registros, acontecimientos, fotografías ni fuentes. Todo dato futuro tendrá procedencia y estado de calidad.

### Arquitectura inicial

- `index.html` — experiencia principal.
- `css/styles.css` — sistema visual responsive.
- `js/app.js` — navegación e interacción.
- `data/climate-schema.js` — contrato de datos para futuras fuentes.

### Principio técnico

GitHub Pages + HTML/CSS/JS modular. Primero construimos el motor y la experiencia; después conectamos fuentes reales. Cuando un dato no exista, se muestra como no disponible: nunca se rellena con invenciones.
