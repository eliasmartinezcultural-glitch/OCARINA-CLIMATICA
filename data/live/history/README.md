# Series históricas normalizadas

Este directorio contendrá archivos generados por ingestores, separados por fuente y estación.

No se cargan datos manuales directamente en la interfaz.

Cada registro deberá conservar estación, fecha/hora, variables, fuente, dataset, momento de recuperación y cobertura.

Una serie no se presentará como histórica completa hasta conocer su período y calidad de cobertura.
