# Proveniencia y referencias

Cada dato visible debe poder responder cinco preguntas en pocos segundos:

1. ¿Qué es?
2. ¿De dónde salió?
3. ¿Cuándo fue medido, producido o recuperado?
4. ¿A qué lugar corresponde?
5. ¿Qué transformación sufrió antes de mostrarse?

## Ficha pública recomendada
**Fuente · estación/producto · fecha/hora · evidencia · unidad · cobertura · estado de calidad · método · enlace original.**

## Multimedia
Las fotografías, audios, videos, mapas y satélites tienen ficha propia. Una imagen nunca se usa solo como decoración cuando puede inducir a creer que representa una observación meteorológica.

## Derechos
Antes de publicar material comunitario se registra autoría, fecha, lugar, permiso/condición de uso y relación con el hecho. Si no está despejado, no se publica como material definitivo.
