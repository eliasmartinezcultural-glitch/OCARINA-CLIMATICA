# V3.21 · TRONCO 60/40 · PÁGINA CORTA, PROFUNDIDAD INFINITA

## Norte
V3.21 no agrega más superficie. **Reordena la experiencia.**

La pantalla pública debe ser corta, clara y visual. La información no se elimina: se coloca detrás de interacciones simples.

**60 % texto · 40 % visual · 100 % interacción sencilla.**

El porcentaje es una regla editorial de conjunto, no una medición rígida de cada pantalla.

## Dos puertas de entrada

### QUIERO ALGO PUNTUAL
La persona debe poder llegar a un dato, pronóstico, historia, definición o fuente con el menor número razonable de acciones.

### QUIERO SUMERGIRME
La persona puede recorrer conexiones, contexto, evidencia, método, documentos y memoria sin abandonar Ocarina.

No son dos sitios. Es **el mismo sistema con dos profundidades**.

## Arquitectura pública
**ENTRAR → ELEGIR → VER → TOCAR → ENTENDER → PROFUNDIZAR → VOLVER**

La portada no debe obligar a recorrer todo.

## Reparación troncal
V3.21 corrige especialmente:
- exceso de superficie vertical;
- repetición de módulos;
- demasiadas tarjetas pequeñas;
- profundidad visible antes de ser solicitada;
- fuentes genéricas en lugar de créditos exactos;
- capas profundas sin una puerta clara de entrada;
- dependencia de hover;
- pérdida de contexto al profundizar;
- rutas que no explican dónde está el usuario.

## Regla de compresión
**La interfaz se comprime; el conocimiento no.**

Una pantalla puede contener poco a la vista y muchísimo detrás.

## Regla de información
Cada contenido profundo debe distinguir:
1. qué sabemos;
2. cómo lo sabemos;
3. qué significa;
4. qué no permite afirmar;
5. de dónde procede;
6. cómo volver a la lectura simple.

## Regla visual
Pocas composiciones, grandes y memorables.

No se busca llenar la página de elementos. Se busca que cada imagen, color, escala y espacio tenga función.

## Regla de búsqueda
Una persona que llega sabiendo qué quiere debe poder resolverlo sin atravesar la experiencia completa.

## Regla de inmersión
Una persona que quiere aprender puede seguir una cadena:
**fenómeno → explicación → dato → evidencia → fuente → método → archivo → territorio.**

## Multidispositivo
320 / 390 / 420 / 680 / tablet / notebook / desktop.

No se encoge una pantalla de escritorio: se recompone.

## Criterio de aprobación
Una entrega V3.21 solo pasa si es:
**más corta en superficie + más profunda en conocimiento + más sencilla en uso.**
