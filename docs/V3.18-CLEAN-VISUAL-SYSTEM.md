# V3.18 · LIMPIEZA ATROZ Y SALTO VISUAL

V3.18 es una versión de saneamiento profundo y evolución visual. No reemplaza PL1 ni rompe V3.17: elimina superposición, desconexión y fricción mediante capas aditivas.

## Objetivo

**Mucho sistema detrás. Poco sistema visible.**

La interfaz debe sentirse corta, clara, viva y fácil de usar, mientras el motor conserva trazabilidad, estados, accesibilidad y capacidad de expansión.

## Limpieza

Se auditan:
- duplicación de controles;
- capas visuales superpuestas;
- modales que no cierran;
- foco oculto;
- botones sin respuesta;
- estados sin salida;
- enlaces desconectados;
- filtros que no sincronizan estado;
- interacción dependiente de mouse;
- contenido que desborda en móvil;
- exceso de densidad;
- estilos que compiten entre sí;
- efectos sin función;
- dependencias innecesarias.

## Salto visual

V3.18 agrega una capa visual coherente con:
- paleta clima/agua/tierra;
- jerarquía más fuerte;
- superficies y profundidad;
- tarjetas por contexto;
- estados activos claros;
- microinteracciones;
- entrada por Pointer Events;
- adaptación 320/390/680/tablet/desktop;
- reduced motion;
- foco visible;
- controles táctiles cómodos.

## Regla de no acumulación

Si un componente nuevo puede resolverse reutilizando un patrón existente, no se crea otro patrón.

Si dos controles hacen esencialmente lo mismo, se unifican.

Si un efecto no mejora comprensión, orientación o descubrimiento, se elimina.

## Arquitectura

La vista pública mantiene cinco puertas:

AHORA · PRONÓSTICO · 365 DÍAS · HISTORIAS · APRENDER

La complejidad continúa detrás:

IDENTIDAD → FUENTE → CONTRATO → SNAPSHOT → VALIDACIÓN → ESTADO → VISTA → INTERACCIÓN → ACCESIBILIDAD → QA

## Aceptación

No se considera terminada hasta comprobar:
- 320 px;
- 390 px;
- 680 px;
- tablet;
- desktop;
- teclado;
- touch;
- mouse/trackpad;
- reduced motion;
- estados vacíos;
- errores de red;
- búsqueda;
- menú;
- drawer;
- modal;
- navegación entre cinco puertas.

Referencias técnicas: WCAG 2.2 y Pointer Events. La implementación debe mantener foco visible y evitar que barras fijas oculten el foco.
