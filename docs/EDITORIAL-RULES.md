# REGLAS EDITORIALES · OCARINA CLIMÁTICA

## Etiquetas obligatorias
- OBSERVADO: medición identificable.
- PRONÓSTICO: predicción de un sistema de pronóstico.
- DERIVADO: cálculo realizado sobre datos.
- ESTIMADO: modelo, reanálisis o reconstrucción.
- DOCUMENTAL: documento, publicación o registro histórico.
- MEMORIA: testimonio u observación oral local.

## Ficha mínima de un dato
Todo dato publicado debe poder responder:
1. qué se midió;
2. valor;
3. unidad;
4. fecha/hora;
5. localidad;
6. estación o punto;
7. fuente;
8. fecha de obtención;
9. tipo de evidencia;
10. calidad/estado de validación.

## Prohibiciones editoriales
No publicar como hecho confirmado información sin respaldo suficiente. No mezclar categorías de evidencia. No usar lenguaje alarmista para aumentar interés. No usar contenido político o ajeno al clima para atraer audiencia.

## Lenguaje de incertidumbre
Usar expresiones como pendiente de verificación, sin dato local validado, referencia regional, estimado, memoria local o documental cuando correspondan.
