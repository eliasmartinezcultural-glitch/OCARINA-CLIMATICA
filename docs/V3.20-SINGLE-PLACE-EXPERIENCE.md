# V3.20 · EXPERIENCIA DE LUGAR ÚNICO

V3.20 no agrega una webgrafía. Convierte Ocarina Climática en un espacio autónomo de consulta, exploración y memoria.

## Norte
Todo lo necesario para comprender una pieza aparece dentro del proyecto: dato, contexto, evidencia, crédito, fecha, localidad y estado.

## Regla mundial
Una fuente externa puede ser origen del conocimiento, pero la experiencia pública no depende de mandar al usuario fuera. El proyecto presenta la información con atribución visible y conserva la procedencia.

## Reparación profunda
- Eliminar acciones que parecen importantes pero no responden.
- Reemplazar enlaces de salida por contexto interno.
- Conectar inicio, pronóstico, archivo, historias y aprendizaje.
- Evitar duplicación visual.
- Crear una biblioteca visual interna.
- Hacer que las imágenes sean contenido, no decoración gratuita.
- Mantener evidencia separada por tipo.
- Diseñar primero para 320 px y escalar hasta escritorio.
- No usar hover como requisito.
- No sacrificar accesibilidad por espectáculo.

## Arquitectura
IDENTIDAD → FUENTE → CONTRATO → SNAPSHOT → VALIDACIÓN → ESTADO → CONTENIDO → VISUAL → INTERACCIÓN → CRÉDITO → QA.

## Experiencia
MIRAR → TOCAR → DESCUBRIR → ENTENDER → RECORDAR → VOLVER.

## Contenido interno
Cada pieza puede abrir una ficha interna con resumen, evidencia, fecha, localidad, fuente, crédito y notas metodológicas. No es una lista de URLs.

## Imagen
Las ilustraciones internas se identifican como ilustraciones. Las fotografías reales deberán conservar autor, fecha, lugar y derechos antes de publicarse.

## Rendimiento
Las imágenes deberán usar dimensiones explícitas, carga diferida cuando corresponda y variantes responsive. La tecnología de imágenes responsive permite servir recursos apropiados al tamaño y densidad del dispositivo.

## No regresión
PL1 y V3.18 continúan siendo la base congelada. V3.20 es una capa aditiva y reversible.
