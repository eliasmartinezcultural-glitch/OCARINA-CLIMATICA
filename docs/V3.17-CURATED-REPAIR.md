# OCARINA CLIMÁTICA — V3.17

V3.17 es la versión curada, reparada y actualizada transversalmente. No reemplaza PL1: agrega una capa de integridad, accesibilidad, trazabilidad, calidad de datos, búsqueda y QA.

## Se conserva
- AHORA
- PRONÓSTICO
- 365 DÍAS / ARCHIVO
- HISTORIAS
- APRENDER

## Se repara
- búsqueda y retorno al registro;
- foco, Escape y cierre de overlays;
- foco no oculto por la navegación fija;
- estados ARIA;
- cierre del menú rápido al hacer clic fuera;
- contratos ambiguos de fuentes;
- validación de snapshots;
- identidad explícita de release y trazabilidad.

## Se suma
IDENTIDAD → FUENTE → CONTRATO → SNAPSHOT → VALIDACIÓN → ESTADO → VISTA → ACCESIBILIDAD → TRAZABILIDAD → QA

La interfaz sigue siendo deliberadamente simple; la complejidad aumenta detrás de ella.
