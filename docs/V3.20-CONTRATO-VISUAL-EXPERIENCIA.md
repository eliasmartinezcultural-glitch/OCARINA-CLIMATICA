# V3.20 · CONTRATO VISUAL Y DE EXPERIENCIA

## Fórmula
**40 % visual · 60 % texto · 100 % interacción sencilla.**

## Frente
El frente del producto debe transmitir inmediatamente:
- territorio;
- clima;
- color;
- escala;
- profundidad;
- curiosidad;
- confianza.

Debe privilegiar composiciones grandes, imágenes y recursos visuales antes que acumulaciones de botones pequeños.

## Fondo
El motor debe resolver silenciosamente:
- identidad de localidad;
- procedencia;
- clasificación de evidencia;
- calidad;
- estados de disponibilidad;
- validación;
- trazabilidad;
- accesibilidad;
- responsive;
- rendimiento;
- errores;
- reversibilidad.

## Patrón universal
Cada experiencia nueva debe poder responder:

**¿Dónde estoy? → ¿Qué veo? → ¿Qué puedo hacer? → ¿Qué significa? → ¿De dónde viene? → ¿Cómo vuelvo?**

## Regla de escala
### 320–420
Una acción principal por bloque, texto corto visible, imágenes grandes, navegación de pulgar, cero información crítica escondida.

### 680–1024
Más contexto simultáneo, comparación y paneles laterales cuando no perjudiquen lectura.

### Desktop
Mayor composición espacial, mapas, cronologías, comparaciones, visualizaciones y capas documentales.

La experiencia no pierde identidad al cambiar de escala.

## Sistema visual
La paleta puede utilizar color para:
- orientar;
- clasificar;
- distinguir estados;
- crear profundidad;
- conectar fenómenos.

Nunca se utilizará el color como única señal de significado.

## Sistema de imagen
Jerarquía:
1. fotografía local real y acreditada;
2. documento/archivo real;
3. mapa o visualización basada en datos;
4. ilustración interna claramente identificada;
5. recurso decorativo, solo cuando aporte atmósfera sin falsificar información.

## Sistema textual
Jerarquía:
1. titular grande;
2. idea principal;
3. explicación;
4. evidencia;
5. fuente y crédito;
6. método/límite;
7. profundidad documental.

## Sistema de interacción
Los componentes deben tener:
**estado inicial → acción clara → respuesta visible → explicación → retorno.**

## Regla de oro
**Si para usarlo hay que explicar cómo usarlo, primero intentamos rediseñarlo.**

## Regla de profundidad
La complejidad debe estar disponible, pero nunca obligatoria.

## Criterio de aprobación
Una pantalla nueva debe superar:
**REALIDAD + CLARIDAD + BELLEZA + UTILIDAD + ACCESIBILIDAD + RENDIMIENTO + TRAZABILIDAD.**
