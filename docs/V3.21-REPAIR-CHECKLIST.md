# V3.21 · REPARACIÓN PROFUNDA

## Reparar antes de sumar
1. Una sola portada pública corta.
2. Dos intenciones explícitas: puntual / inmersión.
3. Profundidad oculta hasta ser solicitada.
4. No duplicar información entre portada, atlas y universo.
5. No usar tarjetas pequeñas como sustituto de contenido.
6. Cada fuente debe conservar sourceId y crédito exacto.
7. Cada dato conserva evidencia, localidad, fecha, unidad y estado.
8. Toda profundidad tiene retorno claro.
9. Teclado, toque y puntero acceden a las funciones esenciales.
10. 320 px no rompe lectura ni funcionalidad.
11. Movimiento opcional y respetuoso de reduced motion.
12. Ninguna imagen ilustrativa debe parecer una observación real.
13. La superficie se mantiene corta aunque el archivo crezca.
14. El conocimiento puede crecer sin alargar la portada.

## Prueba de 10 segundos
La persona debe entender dónde está, qué es Ocarina Climática y qué puede hacer ahora.

## Prueba de 30 segundos
Debe poder elegir algo puntual, abrir una historia, entrar al pronóstico y decidir si quiere profundizar.

## Prueba de inmersión
Debe poder recorrer:
tema → contexto → evidencia → fuente → método → archivo → volver.
