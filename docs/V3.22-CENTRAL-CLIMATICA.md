# V3.22 · CENTRAL CLIMÁTICA

## Tramo troncal
La primera pantalla se comprime y funciona como una central: **lugar + estado + puertas**.

### Puertas
- Lluvia: serie y método; si no existe estación local verificada, se muestra la ausencia.
- Viento: pronóstico separado de observación.
- Temperatura: pronóstico y evolución.
- Agua/Territorio: relación entre río, riego y paisaje.

Cada puerta lleva a profundidad existente; no crea una nueva navegación principal.

## Representación de San Patricio del Chañar
La portada incorpora una representación SVG explícitamente identificada como ilustración, no fotografía. No se fabrica una fotografía local.

El sistema de fotografías queda reservado para imágenes reales de San Patricio del Chañar con:
- procedencia;
- fecha cuando esté disponible;
- autor/licencia/derechos;
- identificación inequívoca del lugar;
- crédito visible dentro de Ocarina.

## Regla visual
**La primera pantalla orienta en segundos. Las puertas contienen la profundidad.**

No se agregan 20 funciones: se comprime la portada y se aumenta la capacidad de representación.
